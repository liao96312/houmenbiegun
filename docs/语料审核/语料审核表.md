# 后门五分钟 · 真人语料审核表

## 这是什么

从**真人写的**内容里挖出来的语料，用来替换项目里那些「生硬、像教练」的话。

- 来源：**网易云音乐**情绪类歌曲评论区（真人手打，带点赞数。B站评论区因为风控封 IP，这轮没抓到）
- 原始量：5287 条评论 / 1389 组配对；筛完留存如下
- 「分」= 口语度（0-100）。扣分主要扣：书名号引用、名人名言、歌词翻译、排比对仗、音乐评论、模板夸奖
- 「赞」= 这条被多少真人认同。**分高 + 赞高 = 最值得进提示词**
- 「建议」`留`=该留 / `?`=两可 / `删`=文案腔，建议丢
